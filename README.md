# Lunaris

Сайт игры Lunaris.

Сайт: https://retrobanan.github.io/lunaris-site/

## Публикация

GitHub Pages публикует сайт из корня ветки `main`.
Чтобы обновить сайт, измените файлы и отправьте коммит в `main`.
Файл `.nojekyll` позволяет публиковать HTML и ресурсы напрямую.

## Локальный просмотр

Запустите `python3 -m http.server 4173` и откройте http://localhost:4173/.

Содержимое страницы находится в `index.html`, оформление — в `styles.css`,
мобильное меню и копирование контактов — в `script.js`.
Изображения и шрифты хранятся локально в `img/` и `fonts/`.
Лицензии шрифтов включены в `fonts/`.
